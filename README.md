## ВАЖНО: перед запуском отключите антивирус

Перед первым запуском обязательно отключите антивирус или добавьте папку с программой в исключения.

Причины:

- Антивирусы часто блокируют свежескомпилированные .exe файлы
- Windows Defender может удалить RobloxOptimizer.exe сразу после сборки
- Некоторые антивирусы блокируют работу с системными процессами
- Программа использует WinForms и таймеры, что вызывает ложные срабатывания

Как отключить:

1. Windows Defender: Параметры → Обновление и безопасность → Безопасность Windows → Защита от вирусов → Управление настройками → Выключить защиту в реальном времени
2. Добавьте папку с программой в исключения антивируса
3. После сборки добавьте RobloxOptimizer.exe в белый список

После отключения антивируса запустите build.bat заново.

## Быстрый старт

### Требования

- Windows 7 / 8 / 10 / 11
- .NET Framework 4.0+ (уже есть в Windows 10/11)
- Отключённый антивирус или добавленная папка в исключения

### Сборка

1. Склонируйте репозиторий:

   git clone https://github.com/YOUR_USERNAME/roblox-optimizer.git
   cd roblox-optimizer

2. Поместите RobloxOptimizer.cs и build.bat в одну папку.

3. Отключите антивирус (см. раздел выше).

4. Запустите build.bat двойным кликом — скрипт соберёт RobloxOptimizer.exe и запустит его.

5. Или скомпилируйте вручную:

   C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /out:RobloxOptimizer.exe /reference:System.Windows.Forms.dll /reference:System.Drawing.dll RobloxOptimizer.cs

## Частые проблемы

Антивирус удаляет EXE после сборки
Решение: добавьте папку в исключения антивируса и соберите заново.

Windows Defender блокирует запуск
Решение: правый клик по файлу → Свойства → Разблокировать.

Компилятор не найден
Решение: установите .NET Framework 4.5+ с сайта Microsoft.

Ошибка CS2001 Source file not found
Решение: убедитесь, что RobloxOptimizer.cs и build.bat лежат в одной папке.
